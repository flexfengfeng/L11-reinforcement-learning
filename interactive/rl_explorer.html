The catch Each banner has a hidden true click rate. The only way to find the best one is to spend visitors trying them — but every visitor you spend on a weak banner is a click you probably lost. That trade-off is the whole game. Head to Part 2 to let an agent solve it.

Abstract concepts

The same loop runs everything.

Every reinforcement learning system is one loop repeated thousands of times:

An agent looks at its situation, takes an action, gets a reward, and updates how it will act next time.
TermPlain EnglishIn the banner demo
AgentThe learner / decision-makerThe ε-greedy logic
EnvironmentThe world it acts onNorthStar visitors
ActionA choice it can makeShow banner A, B or C
RewardFeedback — bigger is better1 for a click, 0 for none
PolicyIts strategy for choosing“90% best, 10% explore”
Value estimateBelief about how good each action isEstimated click rate per banner

Explore vs exploit — the idea worth keeping

Exploit = use what you know to earn reward now. Explore = give up a little reward now to learn something that pays later. Too little exploration and you lock onto a mediocre choice; too much and you keep gambling on weak options. ε is literally the knob for this balance.

How is this different from supervised learning?

Supervised (L01–L04)Reinforcement (today)
GivenInputs with correct answersNo answer key — only rewards
Feedback“The right label was X”“That choice earned 1” (never the best)
Sarah exampleClassify a review +/–Learn which banner earns clicks
Key takeaway Reinforcement learning = learning a policy (a habit of acting) from rewards (feedback on actions), while balancing exploration against exploitation. Everything else is detail.

Where this leads Add the idea that your action changes the next situation, and you reach full reinforcement learning — optimising long-term reward over a sequence of decisions (chess, robotics, checkout flows). The same loop, scaled up, is also how modern chatbots are tuned: RLHF asks people which of two answers they prefer, trains a reward model on those choices, and uses it as the reward.
